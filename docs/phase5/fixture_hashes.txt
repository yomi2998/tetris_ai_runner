# Phase 5 policy fixture provenance

Corpora, one per contraction contract:

9d1bdf59d8f5f50a694ab60f8436cbf6966c9aac212e4257b9216b4988dc2a29  fixtures/toj_policy_v2.csv
7ae9e6c240a431a5f9758d440a2ad1adec4c828afb7b42b803909d60252cdba8  fixtures/toj_policy_v2_nofma.csv

Both hold 7,167 cases over the same 44 board tags with identical
non-floating fields in every row (asserted per row by the test).
The FMA file comes from the release command below; the non-FMA file
comes from `./out/build/linux-gcc-debug/migration_fixtures policy_v2
/tmp/nofma 24 1` (both debug builds agree byte-exactly). The test
gates the file matching its declared build contract.

Category coverage (asserted per category by the test): clears 0
through 4, spin inputs none, full, and mini, full spins at clears 1,
2, and 3, T2 and T3 gains, death, perfect clear with live bonuses at
nonzero safety, all parent, hold, next, arrival, and witness
categories, and config-safe variants 0, 5, and 16 cycling by case.

Generator command (run from the repository root):

./out/build/linux-gcc-self-release/migration_fixtures policy_v2 docs/phase5/fixtures 24 1

Byte determinism: two consecutive runs with the committed generator
produce byte-identical output (verified with cmp).

Engine safety: the generator sets `ai_config()->safe` per case from
{0, 5, 16} and records it in the `cfg_safe` column after validation
found that field uninitialized on the engine path. Values 5 and 16
sit above the T2 (4) and T3 (10) safety margins so slot scoring stays
live. Regeneration from the pinned generator reproduces the committed
bytes exactly.

Cross-compiler comparison against the committed bytes, fresh on the
final corpus:

- GCC debug and Clang debug: 3,313 lines differ, all floating point,
  maxima 7 ULP in a resulting-state value, 2 ULP in an evaluation
  value, 64 ULP in one accumulation (case 5353). Zero non-floating
  differences. Both debug builds agree with each other exactly.
- Clang self-release: 117 lines differ, maxima 1 ULP. Zero
  non-floating differences.
- The variation tracks fused multiply-add contraction, not compiler:
  rebuilding legacy with `-ffp-contract=off` or generic `-march`
  reproduces the debug-side bytes exactly, while `-O3
  -march=native` reproduces the committed bytes bit-exactly. The
  64 ULP outlier is rounding amplified by cancellation in a
  death-penalty accumulation, measured legacy-versus-legacy on
  identical inputs with all integer fields equal.
- Parity gate allowance: 5 ULP on finite doubles, exact on
  everything else, enforced directly against the selected frozen
  file. Measured frozen peaks: 0 ULP in GCC self-release, at most 1
  ULP in Clang self-release, 0 ULP in both debug builds and the
  sanitizer build against their non-FMA file. A committed negative
  suite plus file-level corruption probes prove corrupted frozen
  integers and nonfinite frozen floats fail.
