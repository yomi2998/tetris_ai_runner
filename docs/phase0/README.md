## Independent spec oracle

`spec_oracle` (temporary target): 3,457 checks, 0 failures under GCC
self-release and Clang debug. Hand-authored from the published SRS
specification, not from legacy output:

- Precomputed CW/CCW kick candidate sequences match the published JLSTZ and I
  tables in exact order, wall-bounds filtered, for all pieces, orientations,
  and positions
- Basic rotation equals the direct (identity-kick) candidate
- Direct 180 rotation reaches the opposite orientation pattern
- Row-array board transitions for hand-computed line clears (bottom-origin
  rows; legacy `map.top` is one above the highest occupied row per column)
- 432 legacy-generated paths replay exactly through an independent scalar
  interpreter using the published kick tables and a column-top collision model

Frame finding recorded for the port: the legacy engine trims piece bounding
boxes, so each rotation state has a measured status-to-cells anchor. The I
piece spawns in its upper horizontal orientation (row y=2 of the 4x4 box).
Legacy rotation states and first-valid kick order are otherwise identical to
the published tables after this frame conversion. This is the seed of the
`ExternalPoseTransform` table required by plan Section 9.1.
